# 免版权图源 — Free Image Sources

> **角色**：实景参考图获取指南 —— 搜索降级链 + 来源标注 + 使用纪律。供 Phase 1 / 3 / 3.5 / 6 检索真实场景参考照片（地标 / 建筑 / 自然景观 / 城市街景），弥补 AI 生图在实景上的偏差。
> **边界**：仅检索与下载（获取后本地化）；不改变编译器「不执行网络请求」边界。版权不作为过滤/阻断条件（2026-09-28 裁定：所有来源均可输入模型；许可信息仅作事实记录）。
> **宪法位置**：`references/free-image-sources.md` — 交叉关注点，放 references 根目录。
> **最后更新**：2026-09-28 | v0.31.0

## 适用场景

分镜 / 美术需要**真实场景参照**（地标、建筑、自然景观、城市街景）且用户未提供实景照片时使用。主要触发点：

- **Phase 6 子步骤 4.5**（分镜需要特定地标/元素参考 —— 主要入口）
- Phase 1 用户描述具体地点但未提供照片（氛围参考）
- Phase 3 AD 场景 mood 参考 / Phase 3.5 实景 vs AI 生成对比

> ⚠️ 教训（2026-06-30 猫游广州实测）：AI 生图的桥梁拱圈 / 地铁站位置与真实结构存在偏差。真实场景参考的优先级：**用户实拍 > 搜索实景图 > AI 生成 moodboard（仅最后手段，且须标注「AI 生成，非实景」）**。

## 搜索降级链（默认顺序）

```
① Wikimedia Commons（免 key，开放平台，中文地标覆盖好）
     │ 未命中或覆盖不足
     ▼
② Unsplash → Pexels → Pixabay（官方 API，需会话级 key —— 决策 7A）
     │ 未命中
     ▼
③ 兜底：提示用户补充
   「无法找到 [地标名] 的实景照片。建议您提供一张本地照片，
     或选择 AI 生成 moodboard 代替（⚠️ AI 生成场景可能与实景存在偏差）」
```

> 顺序按**工程可用性**排列（免 key 源优先），非许可排序。

## 图源要点

| 图源 | Key | 限流（参考） | 中文地标覆盖 | 备注 |
|------|-----|------------|-------------|------|
| **Wikimedia Commons** | 免 key | 宽松（开放平台） | ✅ 好（如「广州塔」「猎德大桥」） | 默认首选；API 返回结构化元数据（可从 extmetadata 提取作者） |
| Unsplash | 需 key | 50 req/h | ⚠️ 西方建筑为主 | 官方 API |
| Pexels | 需 key | 200 req/h | ⚠️ 同上 | 官方 API |
| Pixabay | 需 key | 100 req/h | ⚠️ 同上 | 官方 API |

**反爬注意**：百度图片 / 谷歌图片等无官方 API 的源**不做自动抓取**（反爬严格、版权不明）——需要时仅提示用户手动补充。

### Wikimedia Commons 检索要点

- 关键词中英并试（「广州塔」/「Canton Tower」）
- 搜索命中条目后取图片直链（imageinfo.url）+ 页面 URL（descriptionurl）+ 作者（extmetadata.Artist）
- 来源标注：作者 + 平台写入 `file_registry` 的 `credit` / `origin_url`（溯源元数据）

### 会话级 key 源（决策 7A）要点

- key 由用户在会话中提供（临时环境变量），**不入库、不写入任何 skill 文件**
- 用户未提供 key → 跳过本层，直接走兜底
- 命中后按来源标注：`source: "search"` + `credit: "<作者> · <平台>"` + `origin_url`

## 使用纪律

1. **下载到本地再引用**：搜索结果**必须下载**至 `projects/<name>/frames/`（远程 URL 可能失效），以本地路径嵌入 storyboard / file_registry —— 不允许直接把远程 URL 写进 storyboard panel。
2. **注册表登记**：每张获取图登记到 Project State **顶层 `file_registry`**（条目含 `local_path` / `role` / `weight` / `source: "search"` / `credit` / `origin_url`）。
3. **输入模型**：搜索图与用户提供 / 生图生成**同等**进入 `image_ref` 模型引用路径（2026-09-28 裁定；来源标注仅作溯源）。
4. **限流纪律**（防止管线卡死）：
   - 单次管线运行 ≤10 次 API 调用（精选，不全量搜索）
   - 同关键词结果 1 小时内缓存，不重复请求
   - 任何超限 / 超时 → 降级为兜底提示，**不阻塞管线**
5. **只搜用户没有的**：用户已提供参考图 → 跳过搜索。

## 与编译链的关系

获取的实景参考图在 Phase 7.5 作为 `image_ref` 输入（weight 建议：场景 mood 0.5-0.7）。编译器只消费 file_registry 中已有条目；搜索 / 下载动作全部由 Agent 在编译前完成。
